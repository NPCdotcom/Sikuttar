# Design deliberation — workflow detail

Decide **what to build** at the current **H level**（`lifecycle-reference`）. P4 planning → **plan_slicer**.

## Steps

0. **Research** — 探索型 → **`landscape-research`** · 用語 → `prop.design.terminology_first` / `cap.research.terminology`（両方必要なら landscape 先）
1. `act.design.identify_unfixed_h` — which H is unfixed?
2–6. `act.design.deliberate`（Goal → Options → Recommendation → Open → `>`）
7. Next: `act.design.record`
