# Landscape Research

**Role**: PM / `spec_designer` / `kit_maintainer` · **探索型** · WebSearch (+ browser 任意)

**方針**: **広く浅く → 搾る**。第1波で答えを書かず **地図** を書く。  
設計問いでは Frame に **C-factor / C-message / C-recognition / C-stack** を混ぜてよい（OOP 一択・言語必須化は禁止）— `docs/LANDSCAPE_RESEARCH_POLICY.md` · `docs/DESIGN_SEMANTICS.md`。

## vs terminology-research

| landscape-research | terminology-research |
|--------------------|---------------------|
| 5–7 軸 · 並列 scan | 3–8 **用語** · 権威定義 |
| 2–4 点だけ drill | 用語ごと深い |
| landscape report | alignment 表 |
