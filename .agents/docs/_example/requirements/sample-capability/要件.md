# 要件定義（例: sample-capability）

親: [要求.md](./要求.md)

## スコープ

### In scope

- 一覧 UI から 1 件以上選択し CSV を 1 ファイルで取得
- 件数上限（例: 10,000）を超えたらエラー表示

### Out of scope

- スケジュール出力、メール送信、PDF

## 機能要件

| ID | 要件 | 検証方法 |
|----|------|----------|
| FR1 | 1 件以上選択しないと出力ボタンは無効 | UI テスト |
| FR2 | CSV は UTF-8、ヘッダ行あり | ファイル検査 |
| FR3 | 上限超過時は理由付きエラー | 境界テスト |

## 非機能要件

| ID | 要件 | 検証方法 |
|----|------|----------|
| NFR1 | 10k 件で 60 秒以内（目標） | 負荷試験（後続 plan） |

## エージェント提案

**推奨**: 出力処理を独立 program（H4）にし、algorithm（H5）は CSV エスケープのみ分離可能。
