# Generic example artifacts（削除可）

**中立サンプル** — 特定プロダクト・業界・エンジンに紐づかない。利用先では:

1. 構造の参考にする、または
2. 必要なファイルだけ `docs/` へコピーして **リネーム・置換** する
3. 本フォルダ `_example/` はコピー後 **削除してよい**

| パス | 用途 |
|------|------|
| `project-state.yaml` | P0 初期状態の例 |
| `requirements/sample-capability/` | P1–P2 の書き方例 |
| `design/product/charter.md` | P0 charter 例 |

プラン例: `.agents/plans/_example/algorithms/sample-transform.md`
