# Capability wave 2 — 再評価

親: [charter](charter.md) §8 · 着手順。本波は §8 を **関数追加で拡張**する（並行 SNS 分類ツリーは立てない）。  
**agreed 2026-10-17**（認証 GitHub OAuth · タグ候補リスト · CF デプロイ境界）。

## ユーザー方針（2026-10-17）

| 案 | 方針 |
|----|------|
| 検索 | **厚く**（意味検索）。Cloudflare 前提 · デプロイ視野 · 料金トレードオフ明示 |
| アカウント | **A+B**: 内部属性編集（非表示）＋ 持続アカウントを DB 行に紐づける（公開プロフィールなし）· **GitHub OAuth** |
| ハッシュタグ | 採用（失敗談の**分類タグ**）· 候補語彙＋任意追加 |
| ブックマーク | 採用（個人保存 · 公開リストなし · ログイン必須） |
| CF デプロイ | **最低限公開できる段階でまとめて**上げる。ローカルで足りる間は頻繁に上げない |

## 再評価サマリ

| 能力 | 製品価値 | 匿名（E8）適合 | CF コスト感 | 依存 |
|------|----------|----------------|-------------|------|
| 意味検索 | 高（蓄積の発見） | 可（クエリは本文対象） | Workers AI + Vectorize。Free 枠で実験可、本番は Paid 検討 | 投稿永続化・埋め込みパイプライン |
| アカウント A+B | 中〜高（跨端末・属性） | **必須**: 表示名なし · 一覧に身元なし | D1 のみ（低） | 認証プロバイダ選定 |
| 分類タグ | 高（索引） | 可 | D1（低） | 検索／一覧フィルタと相性良 |
| ブックマーク | 中 | 可（非公開） | D1（低） | **B（持続アカウント）が前提** |

## Cloudflare トレードオフ（Assumption · 要実測）

Facts（ドキュメント上の目安 · 2026-10 時点の公開料金表）:

- Workers Free: リクエスト等に上限あり
- Workers AI: 無料割当 **約 10,000 Neurons / day**。超過は Workers Paid ＋ Neuron 課金
- Vectorize: Free に queried/stored dimensions の枠あり。**本番利用は Workers Paid が必要な場合あり**（アカウントで要確認）

設計方針:

1. **ローカル／未バインド**: 現行 D1 Jaccard（S3）をフォールバック（課金ゼロ）
2. **CF デプロイ（推奨構成）**: D1 + Workers +（Paid 時）Vectorize + Workers AI 埋め込み
3. **フィーチャフラグ**: `SEMANTIC_SEARCH=vectorize|fallback` で切替
4. **ハッカソン規模**: 投稿数千・クエリ少なめなら Free/Paid 最小でも足りやすい。LLM 長文生成はしない（検索＋既存本文提示）

## 認識単位の追加（§8 拡張 · 提案）

| ID | 認識単位 | 一文 |
|----|----------|------|
| E9 | 意味検索照会 | クエリに近い失敗談をベクトル類似で返す |
| E10 | 分類タグ | 失敗談に付く検索・絞り込み用ラベル（通称ハッシュタグ） |
| E11 | 個人保存（ブックマーク） | 利用者が後で読むための非公開保存 |
| E7′ | 持続アカウント紐づけ | 認証 subject を accounts 行に結ぶ（表示はしない） |

E7（属性内部保持）は A として UI 編集を許可するが **フィードに出さない**。

## やらないこと（本波）

- 公開プロフィール · フォロー · 表示名必須
- コメントスレ · BAD 公開
- 自由炎上タグの無制限運用（初期は語彙制約を推奨）
- 検索結果での身元特定 UI

## Cloudflare デプロイ境界（合意）

```text
[ローカル完結] ──頻繁に CF へ上げない──▶ 開発・フォールバック検索
[wave2 公開一式がデモ可能] ──まとめて──▶ 初回 CF デプロイ（D1 remote · OAuth · フラグ）
[意味検索を本番オン] ──直前──▶ Paid 要否確認 · Vectorize 作成
```
