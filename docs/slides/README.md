# Sikuttar — 発表スライド（Reveal.js）

PowerPoint ではなく、ブラウザで全画面発表する HTML デッキです。

## 開き方

| 方法 | URL / 操作 |
|------|------------|
| GitHub Pages（マージ後） | `https://npcdotcom.github.io/Sikuttar/slides/` |
| ローカル | このフォルダの `index.html` をブラウザで開く（オフライン可 · vendor 同梱） |

操作: 矢印キー / スペースで進む · `F` で全画面 · `S` でスピーカーノート（未使用） · `Esc` で一覧。

## 構成

- `index.html` — スライド本体
- `vendor/reveal.js/` — Reveal.js 5.1（CDN 非依存 · 会場オフライン向け）

詳細な製品説明は [Wiki](https://github.com/NPCdotcom/Sikuttar/wiki) を参照。
